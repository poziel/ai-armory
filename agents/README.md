# Sub-agents

Store reusable sub-agent definitions here, grouped by tool when their formats differ, for example `agents/tool-name/code-reviewer.md`.

For each definition, document:

- Its role and when to invoke it.
- The inputs it needs and the output it should produce.
- Its supported tool, available capabilities, and permission boundaries.
- Where to install it and how to invoke it.

Use the target tool's native format. Add a companion `README.md` when setup information does not belong in the definition itself.
