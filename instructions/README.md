# Instruction templates

Store reusable project instructions here. Group related templates by purpose, for example `instructions/vue-project/AGENTS.md` or `instructions/code-review/CLAUDE.md`.

- Use the filenames expected by the target tool.
- Use `{{PLACEHOLDER_NAME}}` for values that must be customized.
- Include a companion `README.md` explaining the intended project, supported tool, placeholders, and destination path.
- Review and replace placeholders before copying a template into a project.

Files here are templates. The repository's own working instructions live in the root `AGENTS.md`.
